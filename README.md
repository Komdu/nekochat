# nekochat
ws-only (может быть) платформа для чатов
![nekochat](https://github.com/Komdu/nekochat/blob/main/assets/banner.png?raw=true)
![screenshot](https://github.com/Komdu/nekochat/blob/main/assets/screenshot.png?raw=true)

nekochat это штука что бы чатится, звонить и т.д.

# чё как настроить?
ты можешь подключиться к серверу через клиент (оффициальный) или через кастомный клиент (через [api](https://nekochat.komdu.is-cool.dev/api/docs))

ну сервер тоже довольно просто развернуть, нужно скачать NekochatServer.exe и он запустит сервер на localhost:8001, данные в %APPDATA%\NekochatServer
что бы подключится к любому серверу нужно вписать его в строку server (первый логин), или нажать кнопку выключения в клиенте и там указать (после логина)
