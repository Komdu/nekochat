# Тесты nekochat

Проверяют то, что нельзя поймать при беглом взгляде на клиент: формат бинарных
кадров, приоритеты очередей, квоты файлов, сквозной звонок и — отдельно —
реальный интерфейс в браузере.

Все скрипты бьют по **живому локальному серверу**, кроме `nko-test-queue.py`
(чистые юнит-тесты, сервер не нужен).

## Запуск сервера

```powershell
cd D:\nekochat
$env:NKO_PORT=8001
$env:NEKOCHAT_DATA_DIR="$env:TEMP\nko-test"
.\.venv-build\Scripts\python.exe server_win.py
```

Два теста (`nko-test-media.py`, `nko-test-quota.py`) ждут порт **8770** — это
задано у них внутри. Один сервер на 8001 их не обслужит.

## Скрипты

| Скрипт | Что проверяет | Порт |
| --- | --- | --- |
| `nko-test-queue.py` | приоритетные очереди, отбрасывание, `IncompleteFrame` — без сервера | — |
| `nko-test-media.py` | релей аудио/видео 1-1 и по комнате, формат кадра, фолбэк | 8770 |
| `nko-test-quota.py` | квоты файлов: одна передача, освобождение слота | 8770 |
| `nko-call-e2e.py` | сквозной звонок: `call` → `call_answer` → аудио → `call_hangup` | 8001 |
| `nko-svelte-check.py` | отдаётся ли собранный клиент, живы ли его REST/WS, работает ли бинарный канал | 8001 |
| `nko-ui-shot.py` | **интерфейс в настоящем браузере**: вход, отрисовка, тема, свои/чужие сообщения | 5173 |

```powershell
.\.venv-build\Scripts\python.exe tests\nko-test-queue.py
```

## Про `nko-ui-shot.py`

Гоняет установленный Edge в headless через CDP: заходит на клиент, вводит логин
и пароль **как живой человек** (в DOM, а не подменой токена), проверяет, что
нарисованы список, сообщения, аватарки, кнопка звонка и OLED-фон, и делает PNG.

Нужен запущенный dev-сервер клиента:

```powershell
cd D:\nekochat\web
npm run dev        # http://localhost:5173/web_next/ — именно localhost, не 127.0.0.1
```

Перед прогоном ставит сообщение от второго пользователя: без него в истории
остаются только мои сообщения и нельзя проверить, что свои и чужие действительно
рисуются по-разному. Именно так был найден баг, когда `isMine()` опирался на
поле `user_id`, которого у комнатных сообщений нет — есть только вложенный
объект `user`.

Это единственный тест, который ловит ошибки отрисовки. Остальные проверяют
логику, но не то, что видит человек.

## Чего тесты не проверяют

- Кодирование звука: `AudioEncoder`/`AudioDecoder` живут в браузере, здесь нужны
  живые микрофоны.
- Демонстрацию экрана — по той же причине.
- Сквозную работу через Cloudflare-туннель: локальные тесты идут напрямую.
