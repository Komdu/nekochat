# Roadmap — статус и что дальше

## Что уже есть

**Сервер (FastAPI, REST + WebSocket)**

- Аккаунты (JWT, bcrypt), профили, аватарки, комнаты, личные сообщения.
- WebSocket: онлайн-статусы, комнатные/личные сообщения, **сигналинг-реле для
  звонков уже заложен** (`call*` сообщения в `ws_manager.py`).
- Веб-чат `/web/` (Material You / Win98), лендинг со скачиванием клиента.
- Хостинг: prod `nekochat.komdu.is-cool.dev` (v0.10.0+) через Cloudflare Tunnel;
  PostgreSQL в проде (SQLite локально).

**Нативный десктоп-клиент (новый, React + Tauri)**

- Полный порт старого PySide6-клиента: вход/регистрация, комнаты и ЛС,
  онлайн-точки, аватарки, оптимистичная отправка, зомби-сессия (401 → логаут).
- Темы Material You / Win98 + **кастомная тема из файла** (`theme.json`).
- Релиз: `dist\Nekochat-desktop.exe` (release), NSIS-установщик (~2 МБ).
- Паритет палитры с Python сверяется компаратором (`tmp/pal_test/`).

## Что дальше (по приоритету)

1. **Отдавать React-фронтенд с сервера как веб-страницу** — тот же код, что и в
   десктопе, на `https://nekochat.komdu.is-cool.dev/web/` (CORS уже открыт).
   - Заменить/дополнить старый `/web/` (веб-чат уже работает, но теперь у нас
     один источник фронтенда).
2. **Phase 2: звонки — аудио через сервер (Opus по WS), без WebRTC** —
   сигналинг-реле на сервере готов.
   - ✅ **1-1 голосовые звонки в клиенте**: `CallEngine` (микрофон →
     `AudioEncoder`(opus) → `call_audio` по WS; приём → `AudioDecoder` →
     джиттер-буфер), оверлей звонка (входящий/исходящий, принять/отбой, мьют,
     таймер), кнопка 📞 в шапке ЛС. Сервер — только реле аудио и сигналинга.
   - ⏳ Комнатные звонки (реле уже умеет `room_id`), проверка на двух клиентах,
     возможно — видео. Пароли: bcrypt на сервере (уже так).
3. **Судьба старого PySide6-клиента** — оставить как запасной вариант или
   удалить после стабилизации `desktop/`.
4. **`/download`** — раздача exe с сервера: ожидает решения (загрузить собранный
   exe на сервер или использовать `download_url` в `config.yml`).
5. **Операционка**
   - Вычистить тестовые аккаунты в проде.
   - Серверные настройки (PostgreSQL, `JWT_SECRET`) не трогаем — генезис прод-конфига.
