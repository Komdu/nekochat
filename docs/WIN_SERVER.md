# Локальный сервер (Windows exe)

`NekochatServer.exe` — автономный сервер для Windows без Docker: FastAPI-приложение,
SQLite-база, REST + `/ws`, статика `/web`, `/docs`, `/admin` — всё в одном файле.

## Запуск

1. Запустите `NekochatServer.exe` — появится консоль с логами.
2. Сервер слушает `127.0.0.1:8001`.
3. В клиенте (Nekochat) на экране входа впишите в поле «Сервер» `http://127.0.0.1:8001`
   и зарегистрируйтесь (регистрация открыта). Адрес запоминается для этого аккаунта.

Остановка — закрыть окно консоли.

## Данные

Все данные лежат в `%APPDATA%\NekochatServer`:

- `nekochat.db` — база (SQLite);
- `avatars/` — загруженные аватары;
- `secret.txt` — JWT-секрет (создаётся при первом запуске; сессии переживают
  перезапуски сервера).

Переопределить папку данных — переменная окружения `NEKOCHAT_DATA_DIR`.

## Сеть и порт

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `NKO_HOST` | `127.0.0.1` | адрес прослушивания |
| `NKO_PORT` | `8001` | порт |
| `NEKOCHAT_DATA_DIR` | `%APPDATA%\NekochatServer` | папка данных |

Для доступа по локальной сети: запустите с `NKO_HOST=0.0.0.0`, откройте порт в
файрволе и указывайте в клиенте `http://<IP-машины>:8001`.

NATS не используется: при `NATS_ENABLED=false` звонки и каналы релеятся через
собственный `/ws`, как и раньше.

## /admin

Админка — `http://127.0.0.1:8001/admin`. Хэш входа генерируется при каждом старте
и печатается в консоль сервера (`ADMIN PANEL HASH: ...`).
