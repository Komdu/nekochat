# Аватарки: ресайз + миграция

## Проблема
Cloudflare-туннель (catch-all на :8000) плохо тянет средние файлы: PNG-аватарки
97–116 КБ (одна 2 МБ) не докачивались (тест: 60 с — только 26 КБ из 98 КБ).
В клиентах вместо фото показывались буквы-инициалы (в т.ч. «Я» у аккаунта «Ян»).

## Решение (сервер, `app/routers/users.py`)
- `_resize_image()` — Pillow: JPEG/PNG/WebP → WebP, JPEG-ориентация (exif_transpose).
- Аватар: ≤192px, q80. Баннер: ≤1280px, q78. Анимированный GIF — как есть.
- Requirements: `pillow==10.4.0`.
- `/avatars` уже отдаёт `Cache-Control: public, max-age=31536000, immutable`,
  а имена файлов содержат случайный hex — после миграции кэша браузера нет.

## Миграция существующих файлов
Скрипт `tmp/avresize.py` (запуск внутри контейнера после пересборки):
```
docker exec -i nekochat-app-1 python - < avresize.py
```
Правила: `N_<hex>.<ext>` → `N_<hex>.webp`, `b_N_<hex>.<ext>` → `b_N_<hex>.webp`;
обновляет `users.avatar`/`users.banner` в БД (id берётся из имени файла), удаляет старые.
Прогон 2026-09-27: resized 18, skipped 2 (битые 70-байтные PNG).
