Что умеет

Чаты

Комнаты и личные сообщения, история, аватары, статусы «в сети».

Голос и экран

Звонки один на один и голосовые каналы комнат, плюс демонстрация экрана.

Свой сервер

Один файл: SQLite внутри, порт 8001, данные в своей папке. Без Docker.

Открытый API

REST и WebSocket, свой клиент — схема в OpenAPI, тексты в /docs.

Свой сервер

Windows — один файл

Запустил exe, зарегистрировался в клиенте по адресу http://127.0.0.1:8001 — готово.

NekochatServer.exe

По локальной сети: NKO_HOST=0.0.0.0. Данные — %APPDATA%\NekochatServer. Подробнее.

Linux / macOS — Python

Те же возможности. Нужен Python 3.11+; база — SQLite, база данных не требуется.

pip install -r requirements.txt
python run.py

Нужен PostgreSQL и NATS? Подними docker compose up — в репозитории есть.
