Что внутри

📚 Адресник

Список своих и чужих серверов, статус «онлайн» прямо в списке, двойной клик — и ты в чате.

🖥 Свой сервер

Один файл: python server.py --db data.db. SQLite по умолчанию, PostgreSQL — если захочешь.

🎨 Material You

Акцент любого цвета — палитра строится автоматически. Или вернись в Win98: тоже тема.

🎙 Голосовые звонки

WebRTC, без серверного веса — сигналинг через WebSocket, медиа напрямую между участниками.

🔌 Открытый API

Кастомные клиенты: REST + WebSocket, документация в /docs и OpenAPI.

🔒 Лёгкий и приватный

Никакой телеметрии. Чат-сервер принадлежит тому, кто его поднял.

Поднять свой сервер — 30 секунд

  1. Python 3.11+ → pip install -r requirements.txt
  2. Запусти: python server.py --db data.db --host 0.0.0.0 --name "Мой сервер"
  3. В клиенте: Добавить сервер → впиши адрес → готово. Сервер сам отдаёт клиентам имя и описание.
python server.py --db data.db --host 0.0.0.0 --port 9000 --name "Мой сервер"
[nekochat] db=sqlite:///.../data.db listen=http://0.0.0.0:9000
